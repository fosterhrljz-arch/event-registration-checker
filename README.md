# 报名表检查器

给活动组织者用的小工具：检查 CSV 报名表里有没有漏填姓名、漏填邮箱、邮箱格式不对、邮箱重复或某行列数不对。页面会告诉你原文件的哪一行出了什么问题，也可以下载问题清单。

## 怎么打开

1. 如果拿到的是 ZIP 压缩包，先右键选择“全部解压缩”。不要直接在压缩包预览里运行。
2. 进入解压出来的文件夹，双击 `index.html`。也可以右键选择“打开方式”，选 Chrome 或 Edge。
3. **成功标志：**浏览器出现“报名表检查器”、白色首页和“上传报名表”按钮。地址以 `file:///` 开头即可，不需要服务器。

普通使用不需要安装 Node、Python 或任何软件包，不用注册或联网。把整个文件夹复制到其他位置、U 盘或另一台电脑后，仍然双击 `index.html`。

## 怎么使用

1. 在 Excel 或其他表格软件里，把报名表另存为“CSV UTF-8（逗号分隔）”。保留第一行列名，例如“姓名、邮箱、票种”。不要直接把 `.xlsx` 改名为 `.csv`。
2. 点击首页或顶部的“上传报名表”，直接选择文件；也可以滚动到上传区，拖入一个 CSV。中文乱码时，展开“文件编码”，试着改成“GB18030 / GBK”。
   **成功标志：**页面进入列名确认区，显示文件名、列数和记录数。
3. 在“姓名列”和“邮箱列”中选对字段。常见列名会自动识别；其他列名可自己选，二者不能选同一列。
4. 点击“开始检查”。**成功标志：**进入独立的白色结果页，显示总报名数、有问题记录数、通过数量三个数字。
5. 点击“重复邮箱”“缺失信息”“邮箱格式”等分类筛选。每条记录默认只显示行号、问题类型和简短信息；点击该条记录，可展开具体原因及全部原始字段，再点一次收起。展开“搜索与更多筛选”后，可以搜索或切换“只看问题 / 全部记录”。每页最多 50 条，超过时出现翻页按钮。手机使用纵向短列表，详细字段自动换行。
6. 点击“导出问题清单”。**成功标志：**浏览器下载一个以“问题清单.csv”结尾的文件。保存位置由浏览器决定，通常是“下载”文件夹。
7. 根据清单的行号回到原表里修改。点击右上角“重新上传”清空本次数据，并选择修改后的 CSV；也可以关闭页面结束。浏览器返回、前进可在介绍和已有结果之间切换；刷新页面会清除内存中的报名数据，需要重新选择文件。

想先看看效果：点击上传区的“使用示例”，或者选择同文件夹中的 `sample-registration.csv`。页面会显示 **9 条报名、6 条问题记录、3 条通过**，重复邮箱分类中有 3 条记录，属于同一组。示例也包含中文、字段内逗号、引号和跨行备注。

## 新界面与动效

首页分为白色介绍、深色识别演示、白色上传三个章节。深色只用于介绍，结果页始终为白色。首页演示数据是虚构示例，不代表当前上传的文件；纸张叠层也不表示工具会修改原文件。

滚动时内容轻轻出现，上传后收起大上传区，检查结束平滑进入结果页。系统开启“减少动态效果”后，会取消位移和过渡，功能保持完整。按钮与记录支持键盘操作，切换到结果后焦点会进入结果标题。检查进度仅表示真实忙碌状态，没有虚构百分比或人为等待。

## 结果怎么看

- **总报名人数**是非全空的报名记录数，包含重复报名，不是去重后的人数。
- 姓名和邮箱去掉前后空白后不能为空。只有这两列是必填项，其他列不做必填检查。
- 同一邮箱去掉前后空白、忽略大小写后相同，就算重复；同组的第一条和后续各条都会标记。只看邮箱，不按同名去重，不合并加号别名或 Gmail 圆点，也不会擅自删除重复记录。错误邮箱也可能同时提示重复。
- “有问题的记录”按记录计数；一条记录可以同时有多个问题，都会列在问题说明中。页面只显示三个统计数字，导出清单仍保留每条记录的问题数量。
- CSV 行号包括表头与原文件空行。带换行的备注会占多行，所以显示范围（例如 `10–11`）。文本编辑器中的物理行号可能与 Excel 左侧的表格行号不同。
- 整行所有单元格都为空或只有空白，会跳过，不算报名；如果某列有备注但姓名、邮箱为空，则会计为有问题的报名。
- 某行比表头多列或少列时仍保留，提示列数不一致。多出来的内容显示为“额外字段”，导出也会保留，方便回查。
- 导出包含**全部**问题记录，不受搜索、筛选和翻页影响。每条记录一行，带原字段、原 CSV 起止行号、记录序号、问题数量和问题详情；多个问题放在同一格。没有问题时导出按钮不可用。

## 本地数据与注意事项

- 报名表只在当前浏览器页面的内存中处理，没有服务器、统计追踪或联网资源，不写浏览器存储。清空或关闭页面后工具不再保留本次数据。浏览器下载记录和你保存的文件仍由你管理。
- 读取操作不会改动用户原文件。导出是另存一份问题清单，请避免在系统保存对话框里手动选择覆盖原文件。
- 为防止 Excel 等软件把姓名、备注等内容当成公式执行，导出时遇到以 `=`、`+`、`-`、`@`（含前导空白）或特殊制表/换行符开头的值，会在前面加一个英文单引号；因此导出用于核对，不保证与原字段逐字节相同。页面显示和原文件不受影响。
- CSV 支持英文逗号、双引号转义、字段内逗号和换行、UTF-8 BOM、CR/LF/CRLF。引号字段内的双引号必须写两次，例如 `"他说""你好"""`。
- 不支持 `.xlsx`、分号或制表符分隔文件，也不支持 UTF-16。推荐另存为 UTF-8 CSV；旧中文 CSV 可选 GB18030 / GBK。
- 空文件、表头缺列名、重复列名、引号损坏、二进制内容会明确报错，不会猜着修复。只有表头的空表允许检查，结果为 0 条。
- 邮箱规则面向常见的 `name@example.com` 写法，支持子域和加号别名；不验证是否真的存在或能收信，不支持中文邮箱、带引号的特殊本地部分、IP 地址域名、单标签内网域名和部分国际化域名。国际化地址可能被提示格式错误，需人工确认。
- 单个文件最大 20 MB，最多 100,000 条报名；大文件读取、搜索和检查可能短暂等待。表格分页，但整个文件仍在内存中。建议将很大的名单拆开检查；不同文件之间不会交叉查重。
- 本次用桌面 Edge 实际检查了桌面及 320–390px 手机尺寸，也检查了平板宽度；手机尺寸是浏览器模拟，并非 iOS/Android 真机测试。未验证 Safari、Firefox 和所有系统版本。不同系统字体会略有差异。浏览器若有阻止本地脚本的企业策略，可能打不开功能。

## 文件说明

请将 `index.html`、`styles.css`、`core.js`、`app.js` 和 `sample-registration.csv` 放在同一文件夹；其他文件是说明和开发测试记录。没有 CDN、在线字体、安装依赖或绝对资源路径。

- `index.html`：入口，双击打开。
- `styles.css`：页面样式，包含窄屏排版。
- `core.js`：CSV 解析、检查和导出逻辑。
- `app.js`：选文件、选列、筛选、分页和下载。
- `sample-registration.csv`：示例报名表，均为虚构数据。
- `tests/`：可复跑的自动化测试和测试文件。
- `records/`：真实命令输出、开发记录、浏览器验证记录。

## 给需要复测的人

普通使用不需要运行命令。如果电脑已安装 Node.js 18 或以上版本，可在本文件夹打开终端，运行：

```powershell
node --test tests/core.test.cjs
```

**成功标志：**最后显示 `fail 0`。测试只读取项目测试数据，不会上传文件或更改用户报名表。实际测试结果和已知验证范围见 `records/`。
