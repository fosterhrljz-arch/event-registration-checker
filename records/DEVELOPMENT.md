# 开发记录

日期：2026-11-02（America/Denver）。以下记录本次实际发生的开发、测试和工具限制，不把未完成的验证写成通过。

## 实现与选择

1. 在当前工作目录新建 `event-registration-checker`，采用无依赖的 HTML、CSS、传统脚本。没有使用在线账户、CDN、在线字体、构建工具或后端。
2. 拆分为页面、样式、核心 CSV 逻辑、界面逻辑。核心逻辑同时被浏览器与 Node 测试调用。页面资源全部使用相对路径，普通打开不需要 Node 或 Python。
3. 实现 CSV 状态机，处理 BOM、逗号、成对双引号、引号内换行、CR/LF/CRLF，并保留每条记录的原文件物理起止行号。异常引号直接给出行号错误；列数异常保留原内容并生成问题。
4. 实现必填校验、常见邮箱格式校验、邮箱规范化与重复分组。重复组全部记录标记，包括第一条；重复消息只列前六个行号，避免几万人同邮箱时生成平方级大小的详情。
5. 实现选文件与拖放、编码切换、列映射、统计、搜索、筛选、50 条分页、清空和 CSV 导出。显示用户数据使用 `textContent`，导出添加 BOM、CSV 转义和表格公式前缀防护。
6. 生成虚构示例和边界测试文件，编写日常语言 README。
7. 补充修复：原报名表本身若已有“检查器_问题数量”或“额外字段 1”等同名列，导出新增列会自动加编号，避免生成重名表头；加入回归测试。

## 实际遇到的问题与处理

- 首次通过 PowerShell 的内嵌 `node -e` 命令生成测试文件，遇到引号转义问题，命令退出码 1，没有生成文件。改为独立的 `tests/create-fixtures.cjs`，执行成功。保留此记录，不把失败当作成功。
- 浏览器工具明确拒绝导航 `file://` 协议；没有通过其他浏览器表面或系统 UI 绕过。改用仅绑定 `127.0.0.1` 的临时 HTTP 预览测试同一套相对资源。交付物本身没有服务器依赖，但“实际双击 file:// 运行”未在本轮完成验证。
- 普通沙箱中临时 HTTP 服务与读取请求无法相互访问：请求先报套接字访问权限问题，提升读取权限后超时。停止该服务后，在允许的权限范围重新启动仅监听本机的服务，确认返回 HTTP 200。没有监听 `0.0.0.0`，没有公开服务。
- 在 Edge 预览中实际点击内置示例，并核对统计 `9 / 6 / 6 / 3`；问题类型筛选为“重复邮箱”时显示 3 条；搜索“王芳”时只显示 1 条。
- 点击导出后页面显示已生成 6 条问题记录。等待浏览器下载事件时工具超时并重置会话，因此没有取得下载文件路径，未确认浏览器落盘成功。导出字符串、所有问题记录和复杂字段回读由核心测试验证。
- 使用浏览器支持的文件选择器 API 时，扩展报告缺少“允许访问文件网址”权限；没有更改浏览器权限。随后尝试读取原生文件选择窗口状态，电脑操作工具因无法可靠确认当前浏览器 URL 停止本轮操作。此后没有继续 UI 自动化。
